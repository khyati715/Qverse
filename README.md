Qverse 🌌 – The University Map Reinvented

Overview
Qverse is an innovative, AI-powered university mapping application designed to help students and staff navigate the campus efficiently while enjoying an interactive and visually engaging interface. Think of it as Google Maps for your university, enhanced with real-time data, AI suggestions, and immersive galaxy-themed animations.

Key Features

Campus Navigation – Locate buildings, lecture halls, labs, and facilities with ease.

AI Assistance – Get smart route suggestions, estimated travel times, and personalized directions (ai.js).

Interactive Visuals – Galaxy-themed interface and animations (galaxy.css, galaxy.js) make navigation fun and engaging.

Responsive & Cross-Platform – Works seamlessly on desktops, tablets, and mobile devices.

Firebase Integration – Real-time updates for events, facility status, and user data.

Custom 404 Page – Clean error handling for broken links (404.html).

Why Qverse is Innovative
Qverse takes a standard mapping application and transforms it into an interactive, intelligent experience:

Combines AI-driven suggestions with campus navigation.

Uses visual storytelling and animations to make exploration engaging.

Designed for educational institutions, making it easier for newcomers to navigate complex campuses.

Setup & Installation

Clone the repository:

git clone https://github.com/khyati715/Qverse.git
cd Qverse


Install dependencies:

npm install


Run the server locally:

node server.js


Deploy on Firebase:

firebase deploy
